Research, design, implement and verify a portable small-memory allocator in C99 for bare-metal, FreeRTOS, and POSIX systems. Research existing designs (TLSF, buddy, segregated fits, fixed-block pools) and choose the best design with justification. Hard requirements: O(1) worst-case malloc/free; no libc dependency in the allocator core; operates on a caller-supplied memory region (multiple independent heaps); optional lock hooks for RTOS/thread use; allocator code size under 2 KB on Cortex-M3 (-Os, measured with arm-none-eabi-size); alignment configurable (default 8). Deliverables: allocator source + header, a README with API, design rationale and measured results, and test suites that actually pass on all three targets: (1) POSIX with gcc: unit tests plus a randomized stress test with integrity checks; (2) FreeRTOS using the FreeRTOS-Kernel POSIX simulator port (kernel is provided in the workspace) with multiple tasks sharing a heap via the lock hooks; (3) bare-metal Cortex-M3 built with arm-none-eabi-gcc and run under qemu-system-arm (machine lm3s6965evb or mps2-an385) using semihosting to report results. Report measured code size, worst-case operation counts, and fragmentation results.
